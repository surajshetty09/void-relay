# Void Relay

A one-button orbital slingshot game built with plain HTML, CSS, and Canvas.

Time each launch, let gravity bend the courier's path, and connect the next relay before the signal disappears. Consecutive links increase the scoring multiplier; missed launches consume one of three signal charges.

## Play

- Click, tap, or press `Space` to launch from orbit.
- Reach the glowing `NEXT` gravity well.
- Press `P` to pause.
- Clear the relay quota to unlock the next sector.

No dependencies, build step, or backend are required.

## Run locally

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
